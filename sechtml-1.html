Introducción a HTML: La Estructura de la Web

HTML, o HyperText Markup Language, es el lenguaje estándar utilizado para crear y diseñar páginas web. Define la estructura del contenido web mediante un sistema de 'etiquetas' que envuelven diferentes partes del contenido para que aparezcan o actúen de una determinada manera. Es el esqueleto fundamental sobre el que se construyen todos los sitios web.

Conceptos Fundamentales

Para entender HTML, es crucial familiarizarse con tres conceptos básicos: etiquetas, que definen el tipo de contenido; atributos, que proporcionan información adicional sobre las etiquetas; y elementos, que son la combinación de una etiqueta de apertura, contenido y una etiqueta de cierre.

Ejemplo: Estructura básica de HTML

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>Mi Primera Página Web</title>
    </head>
    <body>
        <h1>Hola, Mundo!</h1>
    </body>
</html>

Lista de Elementos Básicos

  • Etiquetas de Título (<h1> a <h6>): Se utilizan para definir encabezados, donde <h1> es el más importante.
  • Párrafos (<p>): Usados para agrupar bloques de texto.
  • Enlaces (<a>): Crean hipervínculos a otras páginas. El atributo href especifica la URL de destino.
  • Imágenes (<img>): Incrustan imágenes en la página. Los atributos src (fuente) y alt (texto alternativo) son esenciales.

Ejemplo: Combinando elementos

<h1>Mi Blog de Viajes</h1>
<p>Bienvenido a mi blog. Aquí comparto mis aventuras.</p>
<img src="mountain.jpg" alt="Una montaña nevada al atardecer">
<p>
    Lee más sobre mis proyectos en <a href="proyectos">esta página</a>.
</p>

1. Estructura básica y Doctype

<!DOCTYPE html>

Es una instrucción que le dice al navegador que el documento está escrito en HTML5, la versión más moderna del estándar. Evita que el navegador entre en "modo compatible" (quirks mode), un modo antiguo que puede generar errores en estilos y estructura. No es una etiqueta; es una declaración que debe ir siempre en la primera línea del documento.


<html>

Es la etiqueta raíz que envuelve todo el contenido HTML. Define el idioma del documento mediante el atributo lang. Ejemplo: lang="es" indica que todo el contenido está en español.

Esto mejora:

  • Lectores de pantalla.
  • Motores de búsqueda.
  • Traducción automática.

Puede contener atributos como:

  • dir="ltr" (orientación de texto izquierda a derecha)
  • dir="rtl" (derecha a izquierda, usado en árabe o hebreo)

<head>

Contiene metadatos, información técnica que no se muestra directamente.

Elementos comunes:

  • <meta charset="UTF-8">: define la codificación universal para caracteres.
  • <title>: texto de la pestaña del navegador.
  • <link>: cargar CSS externo.
  • <meta name="desciption">: descripción para SEO.

Todo lo que va en <head> ayuda a configurar el sitio, pero no se ve en pantalla.


<body>

Contiene todo el contenido visible del sitio:

  • textos, imágenes, tablas, botones, formularios, etc.

    • Es la capa que muestra la interfaz al usuario final.

    Puede incluir atributos como:

    • onload (ejecutar acciones al cargar la página)
    • class y id (para estilo y scripts)

    Ejemplo:

    <!DOCTYPE html>
    <li>head</li>
        <meta charset ="UTF-8">
        <title>Mi Página<title>
    </head>
    <body>
        <h1>Hola mundo<h1>
    </body>
</html>

    2. Etiquetas de texto y formato

    Encabezados <h1> a <h6>

    Son etiquetas para definir títulos y subtítulos jerárquicos. <h1> es el título más importante; debe usarse solo una vez por página para SEO. Los demás (<h2>, <h3>, etc.) organizan el contenido como capítulos y subcapítulos. Ayudan a lectores de pantalla a navegar por la estructura del documento.


    <p>

    Crea bloques de texto separados. Por defecto agrega un pequeño espacio arriba y abajo para mejorar la lectura. Es la unidad básica para texto largo.


    <strong>

    Aporta importancia semántica. Lectores de pantalla suben el tono para indicar enfasis. Motores de búsqueda lo consideran texto importante.


    <b>

    Solo cambia la apariencia del texto (negrita visual). No indica importancia ni tiene valor semántico.


    <em>

    Indica énfasis semántico real (cambia la entonación en lectores de pantalla). Se usa para resaltar palabras o frases significativas.


    <i>

    Solo muestra el texto en cursiva. Se usa para nombres científicos, palabras extranjeras, etc.


    Ejemplo:

    <h2>Titulo importante</h2>
<p>Este es un  <strong> dato relevantee</strong> y este es solo <b> texto en negrita </b>.</p>
<p> Este texto tiene <em>enfasis real</em> y este solo <i>está en cursiva</i>

    3. Enlaces e hipervínculos

    <a>

    Sirve para crear enlaces que permiten navegar a otras páginas o secciones. Es uno de los elementos fundamentales de la web.

    Atributo principal:

    • href → dirección del destino, que puede ser:
      • URL externa (otro sitio)
      • URL interna (archivo del mismo proyecto)

      Un fragmento del mismo documento usando #.

    Tipos de enlaces:

    • Externos: Conducen a otro sitio web.
    • Internos: Apuntan a otras páginas dentro del mismo sitio.
    • Fragmentos: Navegan a una sección específica, útil para páginas largas.

    target="_blank"

    Abre el enlace en una nueva pestaña. Se usa para:

    • Evitar salir del sitio actual
    • Enlaces a sitios externosl

    Se recomienda añadir también rel="noopener" para seguridad.


    Ejemplo:

    <!-- Enlace externo -->
<a href="https://google.com" target="_blank">Ir a Google</a>

<!-- Enlace interno -->
<a href="contacto.html">Página de contacto</a>

<!-- Enlace a sección -->
<a href="#info">Ir a información</a>

<p id="info">Esta es la sección de información.</p>

    4. Imágenes y multimedia

    Etiqueta <img>

    Inserta imágenes directamente en el documento. No tiene etiqueta de cierre porque es un elemento vacío. Atributos esenciales:

    • src: ubicación de la imagen (ruta local o URL)
    • alt: texto alternativo para describir la imagen

    Es imprescindible para:

    • Accesibilidad
    • SEO
    • Cuando la imagen no carga

    Atributos adicionales:

    • width / height: controlan tamaño.
    • loading="lazy": carga diferida para mejorar rendimiento.

    Importancia del atributo alt

    Los lectores de pantalla leen el texto alternativo. Permite entender el contenido sin ver la imagen. Ayuda a Google a indexar imágenes correctamente.


    Etiqueta <audio>

    Permite agregar audio con controles de reproducción. Atributo común: controls para mostrar play/pausa/volumen.


    Etiqueta <video>

    Permite reproducir videos, también con controls. Puede incluir:

    • poster (imagen previa)
    • autoplay (reproducción automática)
    • loop (repetición)

    Ejemplo:

    <img src="foto.jpg" alt="Foto de un paisaje" width="300">

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>

<video controls width="400">
    <source src="video.mp4" type="video/mp4">
</video>

    5. Etiquetas Semánticas de Estructura (HTML5)

    <header>

    Contiene la parte superior de la página: logo, título, menú principal. Puede aparecer dentro de un artículo o sección.


    <nav>

    Contiene enlaces de navegación principal o secundaria. Mejora la accesibilidad:

    • Los lectores de pantalla pueden saltar directo al menú.


    <main>

    Representa el contenido principal de la página. Solo debe haber uno por documento. Los motores de búsqueda priorizan este contenido.


    <article>

    Contenido independiente que tiene sentido por sí mismo. Usado para:

    • blogs
    • noticias
    • publicaciones
    • comentarios

    <section>

    Bloque temático dentro de una página. Ayuda a dividir contenido en categorías claras.


    <aside>

    Contenido complementario:

    • barras laterales
    • anuncios
    • enlaces sugeridos

    <footer>

    Parte inferior del documento o sección. Incluye:

    • derechos de autor
    • enlaces secundarios
    • contactos

    ¿Cómo ayudan al SEO y accesibilidad?

    Proveen significado al contenido. Los lectores de pantalla pueden navegar por regiones (main, nav, header). Google interpreta mejor qué contenido es importante. Mejoran la estructura general del documento.


    Ejemplo:

    <header>
    <h1>Mi blog</h1>
</header>

<nav>
    <a href="#inicio">Inicio</a>
    <a href="#posts">Posts</a>
</nav>

<main>
    <article>
        <h2>Título del artículo</h2>
        <p>Contenido del artículo...</p>
    </article>

    <section>
        <h3>Sección adicional</h3>
        <p>Información de la sección.</p>
    </section>
</main>

<aside>
    <p>Publicidad o enlaces recomendados</p>
</aside>

<footer>
    <p>Todos los derechors de autor reservados</p>
</footer>

    6. Lista HTML ordenada

    Una lista ordenada comienza con la <ol> etiqueta. Cada elemento de la lista comienza con la <li> etiqueta.

    Los elementos de la lista estarán marcados con números de forma predeterminada, Ejemplo: 

    <ol>
<li>coffe</li>
<li>Milk</li>
<li>Tea</li>
</ol>

    Lista HTML no ordenada

    Esta lista desordenada con la <ul> etiqueta. Cada elemento de la lista comienza con la <li> etiqueta.

    Los elementos de la lista se marcarán con viñetas (pequeños círculos negros) de forma predeterminada:

    Ejemplo

    <ul>
<li>coffe</li>
<li>Milk</li>
<li>Tea</li>
</ul>

    Lista de descripciones HTML

    HTML también admite listas de descripción

    Una lista de descripciones es una lista de términos, con una descripción de cada término.

    La <dl> etiqueta define la lista de descripciones, la <dt> etiqueta define el término (nombre) y la <dd> etiqueta describe cada término:

    Ejemplo:

    <dl>
<dt>coffe</dt>
<dd>Black hot drink</dd>
<dt>Milk</dt>
<dd>White cold drink</dd>
</dl>

    7. Diferencia principal del <div> a <span>

    La diferencia principal es que <div> es un contenedor de bloque que ocupa todo el ancho disponible y crea saltos de línea antes y después, usándose para agrupar secciones grandes de contenido. En cambio, <span> es un contenedor en línea que solo ocupa el espacio necesario para su contenido y no altera el flujo del texto, ideal para aplicar estilos a fragmentos pequeños.


    <div>(De bloque)

    Sirve para agrupar elementos en bloques más grandes, como un título y su párrafo, o para crear la estructura de una sección completa de la página.


    <span>(En línea)

    Se utiliza para agrupar o dar estilo a partes pequeñas de texto o elementos dentro de una misma línea, como una palabra específica dentro de un párrafo.


    8. Estructura de una tabla(<table>)

    <table>

    Una tabla HTML (<table>) es un conjunto de celdas (<td> o <th>) organizadas en filas (<tr>) que a su vez se pueden organizar en grupos de filas (<<thead>, <tbody> o <tfoot>). Además, la tabla puede tener una leyenda (<caption>) y hacer referencia a las columnas (<col> y <colspan>).


    Ejemplo:

    <table>
    <caption>Ejemplo de tabla</caption>
    <tr>
        <td></td>
        <th>A</th>
        <th>B</th>
    </tr>
    <tr>
        <th>1</th>
        <td>A1</td>
        <td>B1</td>
    </tr>
    <tr>
        <th>2</th>
        <td>A2</td>
        <td>B2</td>
    </tr>
</table>

    9. Atributos genéricos

    Los atributos genéricos como id, class, style, title y data-* se aplican a casi cualquier etiqueta HTML para modificar su comportamiento, apariencia o almacenar datos personalizados. id proporciona un identificador único, class agrupa elementos para aplicar estilos, style permite CSS en línea, title muestra información al pasar el ratón y data-* guarda datos personalizados.


    Algunos de estos atributos genéricos:

    • id: Especifica un identificador único para un solo elemento en el documento HTML.
    • class: Agrupa varios elementos que comparten una clasificación. Es útil para aplicar estilos CSS a múltiples elementos a la vez.
    • title: Proporciona un título o una descripción adicional para el elemento, que generalmente aparece como una pista o "tooltip" cuando el usuario pasa el cursor sobre él.
    • data-*: Permite almacenar datos personalizados en el elemento HTML.

    Etiquetas de formularios y entrada de datos

    . La etiqueta <form> crea un formulario en una página web, y las etiquetas como <input>, <textarea> y <button> se utilizan para la entrada de datos del usuario. Los atributos action y method del formulario son cruciales: action especifica la URL a la que se envían los datos y method define el método HTTP (como POST o GET) que se utilizará para el envío.


    <form>

    Define un formulario HTML para recopilar datos del usuario.

    Atributos:

    • Define un formulario HTML para recopilar datos del usuario.
    • method: El método HTTP para enviar los datos (usualmente post o get).

    <input>

    Crea diferentes tipos de campos de entrada en función del atributo type.

    Atributos:

    • text: Un campo de texto simple para la entrada de una sola línea.
    • submit: Un botón que, al hacer clic, envía el formulario.
    • checkbox: Una casilla de verificación que puede estar marcada o desmarcada para seleccionar opciones múltiples.
    • radio: Un botón de opción. Solo se puede seleccionar una opción de un grupo de botones de radio con el mismo nombre.

    <textarea>

    Crea un área de texto de varias líneas para que el usuario pueda introducir texto más extenso.


    <button>

    Define un botón. A diferencia del <input type="submit">, puede tener contenido más complejo (como una imagen) y se puede usar para otras acciones además de enviar el formulario.
