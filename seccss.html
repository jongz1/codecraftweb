Una introducción interactiva a las propiedades esenciales de CSS para dar vida a tus páginas web.

¿Qué es CSS?

CSS, u Hojas de Estilo en Cascada, es el lenguaje que usamos para estilizar un documento HTML. CSS describe cómo se deben mostrar los elementos HTML en la pantalla, en papel o en otros medios. Piensa en HTML como el esqueleto de tu página y en CSS como la ropa y el maquillaje que le dan estilo y personalidad.

Sintaxis Básica

Una regla CSS consta de un selector y un bloque de declaración. El selector apunta al elemento HTML que deseas estilizar. El bloque de declaración contiene una o más declaraciones separadas por punto y coma. Cada declaración incluye un nombre de propiedad CSS y un valor, separados por dos puntos.

p {
    color: blue; /* Esto es un comentario */
    font-size: 16px;
}

Propiedades Fundamentales

A continuación, exploraremos algunas de las propiedades más comunes. Usa el panel interactivo de la derecha para experimentar con ellas y ver los cambios en tiempo real. ¡La mejor forma de aprender es haciendo!

Las propiedades color y background-color te permiten controlar el color del texto y el fondo de un elemento, respectivamente. Experimenta con ellas en la pestaña "Color".

1. Background-image

Permite asignar una o varias imágenes como el fondo de un elemento. Esto añade profundidad, textura o una identidad visual específica a secciones completas de contenido. Su propósito esencial es determinar la imagen que servirá como capa de fondo, cubriendo completamente el área de contenido y el relleno (padding) del elemento. background-image acepta rutas locales, URLs externas o imágenes generadas por CSS (como degradados).

Sintaxis: background-image: none | url() | linear-gradient() | ... ;

Ejemplo: Establecer imagen de fondo de una página

            body {
  background-image: url("paper.gif");
}

2. Background-size

La propiedad background-size especifica el tamaño de las imágenes de fondo. Acepta valores en píxeles, porcentajes o palabras clave como cover (para garantizar que la imagen cubra todo el elemento) y contain (para ajustar la imagen dentro del elemento), lo que permite diseños flexibles y adaptables.

Sintaxis: background-size: auto | cover | contain | width height ;

Ejemplo: Establecer tamaño de una imagen de fondo

body {
    background-image: url("Url/Imagen.com");
    background-size: 400px 450px;
    background-repeat: no-repeat;
}

3. Background-position

La propiedad background-position en CSS se utiliza para definir la posición de la imagen de fondo dentro del contenedor del elemento. Su propósito esencial es determinar desde qué punto del contenedor se mostrará la imagen de fondo, permitiendo controlar exactamente dónde se alinea la imagen y cómo se desplaza respecto al contenedor.

Sintaxis: background-position: left | center | right | x y ;

Ejemplo: Posicionar una imagen de fondo en el centro

section {
    background-image: url("paisaje.jpg");
    background-position: center center;
}

En este ejemplo, la imagen paisaje.jpg se alinea de forma que su centro coincida con el centro del contenedor.

4. Border Width

La propiedad border-width establece el ancho (grosor) de los cuatro bordes del elemento (superior, derecho, inferior e izquierdo). Su propósito esencial es determinar cuán prominente será la línea que separa o enmarca el contenido respecto al resto del diseño visual. El grosor puede indicarse mediante valores absolutos (como píxeles, em, rem, etc.) o mediante palabras clave (thin, medium, thick). Esta propiedad, por sí sola, no mostrará borde alguno si no se ha definido previamente border-style, pues si no hay estilo de borde no habrá dibujo visible.

Sintaxis: border-width: thin | medium | thick | length ;

Ejemplo:
Aplicar un borde de grosor de 5 píxeles alrededor de un elemento:

div {
  border-style: solid;
  border-width: 5px;
}

5. Border Color

La propiedad border-color permite establecer el color de los bordes de un elemento. Su propósito esencial es definir qué tono tendrá la línea que enmarca el contenido del elemento, y permite ajustar visualmente esa “barrera” o “marco” que separa el contenido del resto de la interfaz. Esta propiedad forma parte del modelo de diseño de caja (box model) y se emplea comúnmente para enfatizar, delimitar o decorar secciones, botones, cajas, etc.

La propiedad acepta valores de color (nombres de color, valores HEX, RGB, HSL, con o sin canal alfa) y puede aplicarse de forma unificada a los cuatro lados del elemento o de modo independiente para cada lado (arriba, derecha, abajo, izquierda).

Sintaxis: border-color: color | transparent | initial | inherit ;

Ejemplo:

div {
  border-style: solid;
  border-color: #3498db;
}

6. block-size

La propiedad especifica el tamaño de un elemento en la dirección del bloque. En el contexto de CSS, esto generalmente se refiere a la altura de un elemento cuando el modo de escritura es horizontal (como de izquierda a derecha), o al ancho de un elemento cuando el modo de escritura es vertical (como de arriba abajo).

Sintaxis: block-size: length | auto | fit-content | max-content | min-content ;

Ejemplo:

div {
  block-size: 200px;
}

7. Bottom

La propiedad bottom afecta a la posición vertical de un elemento posicionado. Esta propiedad no tiene ningún efecto sobre los elementos no posicionados.

  • Sí position: absolute; o position: fixed;, la propiedad bottom establece el borde inferior de un elemento en una unidad por encima/por debajo del borde inferior de su antecesor posicionado más cercano.
  • Sí position: relative;, la propiedad bottom hace que el borde inferior del elemento se mueva por encima/por debajo de su posición normal.
  • Sí position: sticky;, la propiedad bottom se comporta como si su posición fuera relativa cuando el elemento está dentro de la ventana gráfica, y como si su posición fuera fija cuando está fuera.
  • Sí position: static;, la propiedad bottom no tiene ningún efecto.

Sintaxis: bottom: auto | length | percentage ;

Ejemplo:

div.absolute {
  position: absolute;
  bottom: 10px;
  width: 50%;
  border: 3px solid #8AC007;
}

8. column-width

La propiedad column-width define el ancho de la columna.

El número de columnas corresponderá al mínimo necesario para visualizar la totalidad del contenido del elemento.

column-width constituye una propiedad flexible. Considere column-width como una sugerencia de ancho mínimo para el navegador. Cuando el navegador no pueda acomodar al menos dos columnas con el ancho especificado, las columnas cesarán su división y se consolidarán en una sola.

Sintaxis: column-width: auto | length ;

Ejemplo:

Especifica que el ancho de columna debe ser de 100px:

div {
  column-width: 100px;
}

9. column-count

Esta propiedad determina la cantidad de columnas en las que se debe fraccionar un elemento, permitiendo crear un diseño de cuadrícula o de múltiples columnas dentro de un contenedor, similar al formato de un periódico o revista. Al especificar un número entero, el contenido del elemento se distribuirá uniformemente entre ese número de columnas, lo que es útil para mejorar la legibilidad y la organización visual del texto en pantallas amplias.

Sintaxis: column-count: number | auto ;

Ejemplo:

Divide el texto en el elemento <div> en tres columnas:

div {
  column-count: 3;
}

10. align-content

La propiedad align-content controla la distribución del espacio entre líneas o grupos de elementos hijos dentro de un contenedor cuando este contenedor tiene varias líneas de contenido (por ejemplo, un contenedor flex con flex-wrap: wrap o un contenedor grid). Su propósito esencial es determinar cómo se colocan esas “líneas” de elementos en el eje transversal (cross-axis) del contenedor, es decir, el eje perpendicular al principal.

Sintaxis: align-content: flex-start | flex-end | center | space-between | space-around | stretch ;

Ejemplo:

Empaque las líneas hacia el centro del contenedor flexible:
div {
  width: 70px;
  height: 300px;
  border: 1px solid #c3c3c3;
  display: flex;
  flex-wrap: wrap;
  align-content: center;
}

11. aspect-ratio

La propiedad aspect-ratio posibilita la definición de la proporción entre la anchura y la altura de un elemento, lo cual es fundamental para el diseño responsivo y el mantenimiento de la coherencia visual.

En caso de establecerse las propiedades aspect-ratio y width, la altura se ajustará automáticamente a la relación de aspecto predefinida. De forma similar, si se establecen aspect-ratio y height, la anchura se calculará para mantener dicha proporción.

Sintaxis: aspect-ratio: auto | width / height ;

Ejemplo:


div {
  background-color: red;
  width: 100px;
  aspect-ratio: 3/2;
}

12. Box Shadow

La propiedad box-shadow permite añadir una o varias sombras alrededor (o dentro) de un elemento. Su finalidad primordial es generar efectos de profundidad visual, elevación, o dimensión en componentes de la interfaz (como tarjetas, botones, paneles), ayudando a que se destaquen o parezcan “flotantes” respecto al fondo.

Sintaxis: box-shadow: none | h-offset v-offset blur spread color inset ;

Ejemplo:

#Etiqueta1 {
  box-shadow: 5px 10px;
}

#Etiqueta2 {
  box-shadow: 5px 10px #888888;
}

13. box-sizing

La propiedad box-sizing determina cómo se calcula el ancho y el alto de un elemento: si deben considerarse (o no) los bordes (border) y el relleno interno (padding). Su propósito esencial es proporcionar un control explícito sobre el modelo de caja (box model) del elemento, permitiendo que el desarrollador especifique si el valor de width y height declarado se aplica únicamente al contenido o abarca también el padding y el border.

Sintaxis: box-sizing: content-box | border-box ;

Ejemplo:

Incluye el relleno y el borde en el ancho y alto totales del elemento:

#example1 {
  box-sizing: content-box;  
  width: 300px;
  height: 100px;
  padding: 30px;  
  border: 10px solid blue;
}

14. Filter

La propiedad CSS filter aplica efectos gráficos como desenfoque o cambio de color a un elemento. Los filtros se utilizan habitualmente para ajustar la representación de imágenes, fondos y bordes.

Hay varias funciones disponibles, como blur() y contrast(), que le ayudarán a conseguir efectos predefinidos.

Sintaxis: filter: none | blur() | brightness() | contrast() | grayscale() | ... ;

Ejemplo:


img {
  border: 5px solid yellow;
}
/* Aplique un 40 % de gris a la segunda imagen y desenfoque 5 píxeles. */
img:nth-of-type(2) {
  filter: grayscale(0.4) blur(5px);
}

15. writing-mode

La propiedad writing-mode especifica cómo se disponen las líneas de texto dentro de un bloque: si se organizan de forma horizontal o vertical, y en qué dirección progresa el flujo de bloques. Su propósito esencial es adaptar la orientación del texto (y el flujo de los elementos de bloque en el contenedor) para soportar distintos sistemas de escritura, idiomas o efectos de diseño.

Sintaxis: writing-mode: horizontal-tb | vertical-rl | vertical-lr ;

Ejemplo:

p.test1 {
  writing-mode: horizontal-tb;
}

p.test2 {
  writing-mode: vertical-rl;
}

span.test2 {
  writing-mode: vertical-rl;
}

16. max-height

La propiedad max-height en CSS se utiliza para establecer la altura máxima de un elemento. Si el contenido del elemento es mayor que la altura máxima especificada, el contenido se desbordará; de lo contrario, no tendrá ningún efecto. Si el contenido del elemento es menor, no tendrá ningún efecto. El valor de la propiedad height puede ser anulado por la propiedad max-height.

Sintaxis: max-height: none | length | percentage ;

Ejemplo:

p {
            max-height: 35px;
            border: 1px solid black;
            overflow: auto;
        }

17. max-width

La propiedad max-width en CSS define el ancho máximo que puede ocupar un elemento, asegurando que no supere un ancho especificado. Esta propiedad desempeña un papel crucial en el diseño responsivo, ya que permite que el contenido se ajuste dentro de un límite definido. Ayuda a crear diseños flexibles que se ven muy bien en pantallas de distintos tamaños.

Sintaxis: max-height: none | length | percentage ;

Ejemplo:

p {
            max-width: 110px;
            color: white;
            background-color: green;
        }

18. min-height

La propiedad min-height en CSS se utiliza para establecer la altura mínima de un elemento. La propiedad min-height se utiliza cuando el contenido del elemento es menor que la altura mínima y, si el contenido es mayor que la altura mínima, no tiene ningún efecto. Esta propiedad garantiza que el valor de la propiedad height no sea inferior al valor de altura especificado del elemento en cuestión.

Sintaxis: min-height: length|initial|inherit;

Ejemplo:

p {
            min-height: 10px;
            border: 1px solid black;
        }

19. min-width

La propiedad min-width en CSS se utiliza para definir el ancho mínimo de un elemento. El valor del ancho no puede ser inferior al valor de min-width. Si el contenido especificado dentro del elemento es más pequeño, min-width mantiene el ancho mínimo especificado.

Sintaxis: min-width: length|initial|inherit;

Ejemplo:

p {
            min-width: 300px;
            display: inline-block;
            color: white;
            background-color: green;
        }

20. line-height

La propiedad CSS line-height establece la altura (también llamada interlineado) entre las líneas de texto en un elemento de nivel de bloque, como un párrafo.

Sintaxis: line-height: length | percentage | number | normal | initial | inherit

Ejemplo:

p {
    line-height: 1.5;
}
div {
    line-height: 300%;
}

21. Opacity

Controla el nivel de transparencia de un elemento completo, incluyendo su contenido e imágenes. Valores cercanos a 0 lo hacen casi invisible, mientras que 1 significa opacidad total. Es ampliamente usado en efectos visuales y transiciones.

Ejemplo:

img {
  opacity: 0.6;
}

22. Visibility

Determina si un elemento es visible o está oculto sin removerlo del flujo del documento. A diferencia de display: none, el espacio que ocupa permanece reservado.

Ejemplo:

p {
  visibility: hidden;
}

23. Cursor

Establece la apariencia del puntero del mouse cuando se coloca encima del elemento. Es útil para indicar interacción (por ejemplo, un botón o enlace).

Ejemplo:

button {
  cursor: pointer;
}

24. Text-align

Define cómo se alinea horizontalmente el texto dentro de un elemento de bloque. Acepta valores como left, center, right y justify.

Ejemplo:

h1 {
  text-align: center;
}

25. Text-transform

Controla la capitalización del texto, permitiendo convertirlo a mayúsculas, minúsculas o capitalizar todas las palabras.

Ejemplo:

p {
  text-transform: uppercase;
}

26. Text-shadow

Agrega sombras a los textos, mejorando la estética y legibilidad sobre fondos complejos.

Ejemplo:

h2 {
  text-shadow: 2px 2px 4px black;
}

27. Letter-spacing

Controla el espacio entre caracteres. Útil para mejorar la legibilidad o estilizar títulos.

Ejemplo:

h1 {
  letter-spacing: 3px;
}

28. Word-spacing

Modifica el espacio entre palabras completas.

Ejemplo:

p {
  word-spacing: 8px;
}

29. White-space

Define cómo se procesan los espacios en blanco dentro del texto, permitiendo evitar saltos de línea o preservar el formato exacto del contenido.

Ejemplo:

code {
  white-space: pre;
}

30. Object-fit

Controla cómo una imagen o video ajusta su contenido dentro de un contenedor con dimensiones fijas, sin deformarse.

Ejemplo:

img {
  width: 200px;
  height: 150px;
  object-fit: cover;
}

31. Object-position

Permite definir qué parte de la imagen se mantiene visible al recortarse con object-fit.

Ejemplo:

img {
  object-position: top center;
}

32. Outline

Dibuja un contorno exterior alrededor del elemento, sin afectar el diseño del modelo de caja. Se usa frecuentemente para accesibilidad (ej. foco del teclado).

Ejemplo:

button:focus {
  outline: 3px solid blue;
}

33. Resize

Permite al usuario redimensionar elementos como cajas de texto, controlando la dirección del cambio de tamaño.

Ejemplo:

textarea {
  resize: vertical;
}

34. Overflow-x

Controla el comportamiento del desbordamiento horizontal de un elemento, permitiendo scroll o corte del contenido.

Ejemplo:

div {
  overflow-x: scroll;
}

35. Overflow-y

Controla el desbordamiento vertical; útil para paneles o contenedores con mucho contenido.

Ejemplo:

div {
  overflow-y: auto;
}

36. Flex-direction

Define la dirección principal en un contenedor flex, pudiendo ser horizontal o vertical.

Ejemplo:

.container {
  display: flex;
  flex-direction: column;
}

37. Flex-wrap

Determina si los elementos flexibles deben ajustarse en varias líneas cuando no caben en una sola.

Ejemplo:

.container {
  display: flex;
  flex-wrap: wrap;
}

38. Order

Permite cambiar el orden visual de los elementos dentro de un contenedor flex sin modificar el HTML.

Ejemplo:

.item {
  order: 2;
}

39. Animation

Permite declarar una animación completa asociada a un elemento, definiendo nombre, duración, repetición y comportamiento.

Ejemplo:

div {
  animation: girar 3s infinite;
}

40. Transform

Aplica transformaciones 2D o 3D como rotar, escalar, inclinar o trasladar un elemento.

Ejemplo:

div:hover {
  transform: scale(1.2);
}

41. Color

La propiedad "color" define el tono visual aplicado al texto dentro de un elemento. Su función es exclusivamente tipográfica, sin afectar fondo, bordes ni sombras. Es una herramienta clave para establecer jerarquías visuales, contraste y legibilidad. Puede utilizarse mediante valores HEX, RGB, HSL o palabras clave estandarizadas, lo cual ofrece alta flexibilidad para adaptar la estética al diseño general. Se puede usar en diferentes formatos como nombres de colores (red), valores HEX (#ff0000), RGB (rgb(255,0,0)), HSL (hsl(0, 100%, 50%)) y más. Esta propiedad es una de las más básicas y esenciales en CSS, ya que forma parte del diseño visual fundamental.

Ejemplo:

p { 
  color: #333333; 
}

42. Background-color

"background-color" determina la tonalidad aplicada al área interna completa del elemento, abarcando tanto el contenido como el espacio generado por el padding. Se utiliza para establecer bloques visuales, separar secciones, guiar la vista del usuario o generar contraste funcional y estético dentro de una interfaz.

Ejemplo:

div { 
  background-color: #f2f2f2; 
}

43. Font-size

Esta propiedad controla el tamaño perceptible de la fuente, influyendo directamente en la legibilidad, jerarquía y experiencia del usuario. Puede utilizar unidades relativas o absolutas, lo que permite diseños escalables, adaptativos o estrictamente controlados dependiendo del contexto y de la importancia del contenido. Puede medirse en píxeles, rem, em, porcentajes o unidades modernas como clamp() para tamaños fluidos.

Ejemplo:

h1 { 
  font-size: 2rem; 
}

44. Font-weight

Define qué tan gruesos o delgados se muestran los caracteres del texto. Sus valores pueden ir desde 100 (extra fino) hasta 900 (extra grueso), dependiendo de la tipografía. También acepta valores como bold, normal y lighter.

Ejemplo:

strong { 
  font-weight: 700; 
}

45. Margin

"margin" determina el espacio exterior que separa un elemento de los que están alrededor. Es esencial para construir estructuras limpias, consistentes y armoniosas, ya que controla la respiración visual entre módulos, tarjetas o secciones enteras del diseño. Puedes definir un margen general o márgenes individuales para cada lado. También permite valores negativos para crear superposiciones. Controlar correctamente los márgenes ayuda a estructurar un diseño limpio y ordenado.

Ejemplo:

.card {  
  margin: 20px; 
}

46. Padding

"padding" representa el espacio interior existente entre el contenido del elemento y su borde. Contribuye a mejorar la legibilidad, balancear el diseño y establecer proporciones claras dentro de componentes como botones, tarjetas y contenedores. A diferencia de margin, forma parte del tamaño total del elemento (modelo de caja). Es esencial para dar aire y mejorar la lectura dentro de tarjetas, botones y contenedores.

Ejemplo:

.card {  
  padding: 15px; 
}

47. Border

La propiedad "border" crea un contorno alrededor del elemento, definiendo grosor, estilo y color. Se usa para generar énfasis, delimitar áreas, reforzar la estructura visual o mejorar la experiencia del usuario mediante indicaciones sutiles de interacción.

Ejemplo:

.box { 
  border: 2px solid black; 
}

48. Border-radius

"border-radius" redondea las esquinas de los elementos, suavizando la apariencia general o creando formas circulares. Es ampliamente utilizado en diseños modernos, amigables y minimalistas, donde las líneas curvas generan una sensación más orgánica y accesible.

Ejemplo:

.btn { 
  border-radius: 12px; 
}

49. Width

Controla el ancho de un elemento, influenciando la forma en que el contenido se distribuye y adapta. Un diseño responsivo suele beneficiarse de valores relativos como porcentajes o unidades de vista, mientras que medidas fijas se emplean para layouts controlados.

Ejemplo:

img { 
  width: 300px; 
}

50. Height

Controla la altura del elemento. Así como width, puede usar unidades absolutas o relativas. Si no se establece, la altura se adapta al contenido. Es importante tener cuidado con alturas fijas para evitar cortar contenido.

Ejemplo:

img { 
  height: 200px; 
}

51. text-indent

La propiedad text-indent especifica la cantidad de espacio horizontal que debe aplicarse antes de la primera línea de texto de un bloque. Su función es crear el efecto de sangría en el párrafo.

Sintaxis: text-indent: length | percentage;

Ejemplo:

p { 
  text-indent: 50px; 
}

52. word-spacing

word-spacing modifica el espacio entre palabras completas en un bloque de texto . Es útil para ajustes fines de tipografía.

Sintaxis: word-spacing: normal | length;

Ejemplo:

p { 
  word-spacing: 8px; 
}

53. list-style-position

Esta propiedad determina si el marcador de lista (viñeta o número) debe colocarse dentro o fuera del flujo del contenido.

Sintaxis: list-style-position: inside | outside;

Ejemplo:

ul { 
  list-style-position: inside; 
}

54. tab-size

tab-size define el número de espacios que representa el carácter de tabulación (\t) al renderizar bloques de código.

Sintaxis: tab-size: integer | length;

Ejemplo:

pre { 
  tab-size: 4; 
}

55. text-orientation

text-orientation establece la orientación de los caracteres dentro de una línea. Es útil cuando se utiliza el modo de escritura vertical.

Sintaxis: text-orientation: mixed | upright | sideways | sideways-right | sideways-left;

Ejemplo:

div { 
  text-orientation: sideways-right; 
}

56. white-space

white-space define cómo se gestionan los espacios en blanco (múltiples espacios, saltos de línea) dentro de un elemento, permitiendo preservar el formato exacto.

Sintaxis: white-space: normal | pre | nowrap | pre-wrap | pre-line;

Ejemplo:

code { 
  white-space: pre; 
}

57. text-shadow

text-shadow añade una o más sombras a los textos, mejorando la estética o la legibilidad sobre fondos complejos.

Sintaxis: text-shadow: none | h-shadow v-shadow blur color;

Ejemplo:

h2 { 
  text-shadow: 2px 2px 4px #000000; 
}

58. font-style

Esta propiedad define si la fuente del texto debe mostrarse normal, cursiva (italic) u oblicua (oblique).

Sintaxis: font-style: normal | italic | oblique;

Ejemplo:

em { 
  font-style: italic; 
}

59. font-variant

font-variant permite que el texto se muestre con una variación tipográfica, como el uso de versales pequeñas (small-caps).

Sintaxis: font-variant: normal | small-caps;

Ejemplo:

h3 { 
  font-variant: small-caps; 
}

60. line-height

line-height establece la altura de la línea (interlineado) entre las líneas de texto en un elemento, crucial para la legibilidad.

Sintaxis: line-height: normal | number | length | percentage;

Ejemplo:

p { 
  line-height: 1.5; 
}

61. text-align-last

text-align-last define cómo se alinea la última línea o la línea inmediatamente anterior a un salto de línea forzado dentro de un bloque.

Sintaxis: text-align-last: auto | start | end | left | right | center | justify;

Ejemplo:

p { 
  text-align-last: center; 
}

62. visibility

visibility determina si un elemento es visible o está oculto (hidden) sin removerlo del flujo del documento (su espacio queda reservado).

Sintaxis: visibility: visible | hidden | collapse;

Ejemplo:

.oculto { 
  visibility: hidden; 
}

63. opacity

opacity controla el nivel de transparencia de un elemento completo. Los valores van de 0 (transparente) a 1 (opaco).

Sintaxis: opacity: number (0.0 a 1.0);

Ejemplo:

img { 
  opacity: 0.6; 
}

64. object-fit

object-fit controla cómo una imagen o video ajusta su contenido dentro de un contenedor sin deformarse (ej. cover o contain).

Sintaxis: object-fit: fill | contain | cover | none | scale-down;

Ejemplo:

img { 
  object-fit: cover; 
}

65. clip-path

clip-path crea una forma de recorte que define qué parte de un elemento debe ser visible. Permite crear formas complejas.

Sintaxis: clip-path: none | <clip-source> | <basic-shape> | <geometry-box>;

Ejemplo:

div { 
  clip-path: circle(50%); 
}

66. box-sizing

box-sizing determina cómo se calcula el ancho y alto del elemento: si deben incluir el padding y border (border-box) o no.

Sintaxis: box-sizing: content-box | border-box;

Ejemplo:

* { 
  box-sizing: border-box; 
}

67. flex-wrap

flex-wrap define si los elementos flexibles deben ajustarse en varias líneas cuando no caben en una sola en el contenedor flex.

Sintaxis: flex-wrap: nowrap | wrap | wrap-reverse;

Ejemplo:

.container { 
  flex-wrap: wrap; 
}

68. gap

gap controla el espacio entre filas y columnas en contenedores grid y flex.

Sintaxis: gap: <row-gap> <column-gap>;

Ejemplo:

.container { 
  gap: 20px; 
}

69. box-shadow

box-shadow permite añadir una o varias sombras alrededor de un elemento (como tarjetas o botones) para generar un efecto de profundidad.

Sintaxis: box-shadow: none | h-offset v-offset blur spread color inset;

Ejemplo:

.card { 
  box-shadow: 0 4px 8px rgba(0,0,0,0.1); 
}

70 filter

filter aplica efectos gráficos como desenfoque (blur), escala de grises (grayscale) o brillo a un elemento.

Sintaxis: filter: none | <filter-function> [<filter-function>]*;

Ejemplo:

img { 
  filter: grayscale(50%); 
}
